# 初回チュートリアル・かんたん設定の設計案

2026-10-10。機能区分整理後の次段として記録した設計案です。**この画面はまだ実装・配布していません。** 現在の操作は[ユーザーガイド](USER-GUIDE.md#拡張機能)を参照してください。

## 分けるもの

- **ノーマル／拡張**：利用する機能・権限の違い。拡張は基本機能への追加で、別アプリや別の設定一式ではない。
- **かんたん設定／詳細設定**：同じ設定の見せ方。かんたん表示へ切り替えても、詳細設定の値や拡張のON/OFFを変更しない。
- **初回チュートリアル**：選んだ使い方だけを案内する導入経路。設定一覧の全項目を順番に説明するものにしない。

## 初回の最短経路案

1. **使い方**：ホームとして使う／今のホームのままDockを使う。ホームの変更は選んだ人だけAndroidの選択画面へ進む。
2. **Dock**：表示するか、左右どちらから出すか、開く方法。初期案は端からスワイプ。横向きの細かい配置は後から変更できる。Dockを使わない場合はoverlay許可を導入の必須条件にしない。
3. **よく使うアプリ**：ピン留めを選ぶ。スキップ可能。Start・Dock・タスクバーのピン保存先を混ぜない。
4. **完了**：実際にDockやStartを一度開く。拡張機能の追加は任意の別導線にし、Shizukuの設定を全員に要求しない。

任意位置ジェスチャーやデスクトップを選んだ人には、その場で拡張の説明・接続・必要な練習を案内する。拡張の接続が完了しなくてもノーマルで始められる。

## かんたん設定に出すもの

| 入口 | 最初に扱う項目 |
| --- | --- |
| ホーム | 試す・標準ホームの選択 |
| Dock | 使用する・出す側・開く方法・大きさ |
| アプリ | よく使うアプリ・表示するアプリ |
| 見た目 | 壁紙・テーマ |
| 拡張機能 | 追加できる機能の説明・ON/OFF・接続 |
| 詳細設定 | 縦横別の細かい位置、タスクバー、外部画面、アプリ別起動設定など |

通知へのアクセスやウィジェットの追加許可は、使う機能の入口で案内する。日常の開始画面に接続待ち・診断情報を並べない。詳しい診断・復元は拡張設定内に残す。

## 先に揃える実装上の境界

2026-10-10のソース確認で、基本起動と拡張接続の分離は存在する一方、表示の整理はまだ残っている。

- `PhoneTaskbar`の撮影ボタンは常時表示だが、`DesktopScreenshot`はBridge経由。ノーマル時は利用できない操作を隠す。
- `QuickSettingsActivity`の本体消灯は拡張用。通常の音量やWi-Fi設定への入口とは分け、利用条件がない場合は消灯操作を隠す。
- Dock設定の任意位置ジェスチャーと外部デスクトップ設定は、通常の端ハンドル設定との違いが分かる配置にする。拡張OFFで既存の選択値を消さない。
- 拡張の保存上のON/OFFと、現在利用できるかを区別する。ONでも未接続なら実行可能扱いにしない。表示だけでなく操作入口でも確認する。

## 保全・完了条件

- 既存ユーザーには初回画面を強制表示せず、任意でやり直せる。再実行・戻る・中断・回転で既存設定を初期化しない。
- かんたん設定も既存の設定所有者と項目別コマンドを使う。設定の別コピーや巨大な一括上書きを作らない。
- 拡張なし／接続中／切断後で基本操作が続くこと、不要な権限を要求しないことを確認する。
- ピン・縦横の設定・外部設定を保持し、未接続の端末で拡張専用操作だけが消えることを検証する。
- 実装・ビルド・端末導入・初回の実操作確認を別々に記録する。
