# Phone Workspace（0.9.0）

## スマホでは通常のAndroidとして使う

1. ダッシュボードの「ホーム画面を開く」でStella HOMEを試します。標準ホームの変更はAndroidの選択画面で任意に行ってください。
2. Androidの「他のアプリの上に重ねて表示」をStellaに許可し、設定 → サイドバー → **サイドバーを使う** をONにします。
3. 通常タップはAndroid標準の全画面起動です。小窓は長押し／右クリック → **小窓で開く** から選びます。

HOME下部のアプリ／設定バーは表示せず、横サイドバーに統一します。Start・検索・グループ・右クリック・設定はDesktopと同じコンポーネントです。専用のPhoneアプリ一覧には切り替えません。重ねて表示の許可がない場合など、横サイドバーを使えない時だけHOME上に同じStartメニューへの入口を出します。

この状態では、通常クリックはAndroidの標準アプリ起動です。Back／Home／Recentsや全画面アプリにStellaのメイン／サブ判定を適用しません。
HOMEを開くとサイドバーを開始し、別アプリを開いても左右の端から呼び出せます。画面を横にしてもPhoneのままです。

サイドバーは **スタート → ピン留め → アクティブ** の縦並びで、上下にスクロールできます。アクティブには本体画面の既存タスクを表示し、押すとそのタスクへ戻ります。新しいウィンドウの起動や外部画面への移動はしません。ピン留めとアクティブは別欄なので、起動中のピン留めアプリは両方に表示されます。
長押し／右クリックのメニューから **サブウィンドウ化**・**タスク終了** ができます。小窓のタスクでは **メインに戻す** に切り替わり、同じタスクをAndroid標準の全画面へ戻せます。変換・終了はいずれも選んだタスクだけが対象で、同じアプリの別タスクには影響しません。小窓化には端末のfreeform機能が必要です。上下はスクロール専用で、スワイプによる小窓化／終了や、そのON/OFF設定はありません。
Stellaのウィンドウ枠・リサイズ操作は、拡張機能の稼働先に選んだ画面が対象です。本体と外部の両方へ同時にStellaの枠を表示する機能はありません。
設定の **サイドバーの呼び出し位置** で上下位置を調整できます。**他のアプリ上でもサイドバーを表示** をOFFにすると、HOME表示中だけ呼び出せます（初期値ON）。外部Desktopのタスクバーには影響しません。

サイドバーのStart・ピン留め・基本HOMEにはShizuku接続は不要です。**アクティブ**のタスク一覧と切り替えにはShizuku接続が必要です。OSのオーバーレイ制限やサービス停止まで回避するものではありません。

Shizukuが接続されていれば、アプリアイコンの長押し／右クリック → **小窓で開く**（Floating）で、その操作だけ小窓にできます。
明示的に小窓で開いたTaskだけがPhone上のウィンドウ管理対象です。対応は端末のfreeform機能・アプリに依存します。
本体では自動のメイン／サブ判定を行いません。過去のウィンドウ管理設定が保存されていても、通常タップは全画面で開きます。

サイドバーに時計・バッテリー・クイック設定は表示しません。本体のAndroid標準UIを利用してください。サイドバーを開いた後、画面の内側へ横スワイプすると、左右に合わせてウィジェットパネルが開きます。専用のウィジェットボタンは表示しません。

## PhoneとDesktopの設定

- PhoneはDisplay 0、Desktopは外部の物理／仮想Displayです。縦横・解像度・Compact表示だけではプロフィールを変更しません。
- ピン留め（Startとサイドバー／タスクバー）、ショートカット一覧と位置、壁紙画像・表示方法・焦点位置を別に保存します。
- 初回だけ既存のピン・ショートカット・位置・壁紙設定をPhoneにコピーします。その後は片方を編集しても他方には反映しません。既存Desktopデータは残します。
- Phoneのサイドバーピンはスクロールでき、Desktop側の6枠とは独立です。
- ウィジェットは既存HOME用Hostと保存先を使用します。HubもPhone用とDesktop用を分離します。AndroidのウィジェットIDはコピーできないため、もう片方に同じウィジェットが欲しい場合は追加し直してください。
- アプリ本体・データ、アイコンテーマ、アプリの非表示／グループ設定は共有です。

## 壁紙

対象のHOME／Desktopから壁紙メニューを開きます。**壁紙の表示位置**でプレビューをドラッグ、または横／縦のスライダーで焦点を指定して保存できます。

- Fill：画面を埋め、指定した焦点を中心に近づけて切り抜きます。画像の端では余白が出ないように位置を制限します。
- Fit：画像全体を中央に収めます。余白が出るため、このモードでは焦点位置は使いません。
- 保存前のキャンセルでは変更しません。回転時は元画像の焦点座標から再計算します。

## 外部画面への切替

Phoneセッションで **接続時に外部画面へ移動**（Workspaceの自動切替設定）を有効にすると、新しい対応外部画面を検出してDesktopへ切り替えます。
初めてPhoneサイドバーを開始し、この設定がまだ存在しなければONにします。既存の明示設定は上書きしません。

Shellの移動とTaskの移動は別です。標準Androidとして起動した電話・決済等のTaskを勝手に取り込みません。
Stellaが管理しているTaskだけ、既存の引き継ぎ経路で移動を試みます。切断時は本体へ戻します。
外部Desktopのタスクバーと、本体Display 0のサイドバーは同時に利用できます。外部へ移した後も本体の別アプリ上からStartを呼び出せます。サイドバー表示ONと重ねて表示の許可が必要です。
外部Desktopの完全なウィンドウ管理には引き続きShizukuが必要です。

## 検証の読み方

JVMで壁紙のFit／Fill・端の制約・異常値を検証し、Android instrumentationで独立したテスト用設定を使って移行／分離と通常起動経路を確認します。
物理USBの抜き差し、OEM別の回転・キーボード・常用HOME運用は、別途実機確認が必要です。ビルド成功を全端末の動作保証とは扱いません。
