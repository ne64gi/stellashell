# おすすめフォント

StellaShellの日本語UIには **Zen Kaku Gothic New（ZEN角ゴシック New）** を候補としておすすめします。SOG06で試したユーザーから、見た目が良いとのフィードバックを得ています。

- [Google Fonts：Zen Kaku Gothic New](https://fonts.google.com/specimen/Zen+Kaku+Gothic+New)
- [フォントファイルとOFL原文](https://github.com/google/fonts/tree/main/ofl/zenkakugothicnew)

Regularから試し、細く感じるならMediumを選んでみてください。見え方は画面のDPI・サイズ・背景色にも左右されます。
フォントはStellaShellのAPKには同梱していません。配布元から取得し、フォント自身のライセンスを確認してください。

## 設定方法

1. 配布ページからダウンロードし、ZIPなら展開。
2. TTFファイルをスマホのDownloadや任意のフォルダーへ保存。
3. StellaShellの **外観設定 → フォントを読み込む** で選択。
4. プレビューを確認して保存。

TTF / OTF / TTC（128 MiBまで）を受け付けます。TTCはコレクション内の書体を選択できます。
適用対象はStellaShell自身のUIです。他アプリ、AndroidのシステムUI、ウィジェット内部のフォントを一括変更する機能ではありません。
