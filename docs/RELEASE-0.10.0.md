# StellaShell 0.10.0 — Event-driven Shell（プレリリース候補）

versionCode: 19 / Shizuku UserService version: 33。ソースcheckpointであり、GitHub Release・配布APKの公開とは別です。v1／安定版ではありません。

## 主な変更

- **待機時のイベント駆動化**：起動中一覧・タスク状態・作業領域・入力先・本体画面状態の常時周期監視を撤去。タスク、画面、入力機器、設定、接続の変化で更新します。閉じたメニューや停止中の画面の不要な描画・通知・ウィジェット処理も抑制しました。
- **Dockとタスクバー**：別機能として本体／外部画面の設定・ピン留めを分離。本体タスクバーは任意、外部画面は常設。Dockの表示位置・バー倍率と画面全体の表示サイズを調整でき、同じ画面にタスクバーがある場合はDockのStartを非表示にします。
- **起動中一覧とウィンドウ操作**：Dockのピン留め済みアプリを一覧から除外し、利用できない一覧は仕切りごと非表示。長押し／右クリックから小窓・全画面へ切替、対象タスクを終了できます。×は対象タスクを直接終了し、スクロールと競合する上下ジェスチャーは追加していません。
- **通知**：アプリ別の件数表示と折りたたみ／展開、最新1件＋残件数のコンパクト表示に対応。個別に開く／消す操作を維持し、まとめ通知の重複を抑制。読み位置、送信者、時刻と通知の存在を示す目印を追加しました。
- **StartのWeb検索**：アプリ検索に加え、あらかじめ設定した検索エンジンで検索。本体画面で検索・設定を開く経路の拒否と、設定ページの表示不具合も修正しました。
- **起動・設定の整理**：Startの設定と共通右クリックメニューを目的別に整理。Android設定は本体で開き、HOMEのStart入口を維持。HOMEでは終了操作を出さず、外部Desktopのセッション終了は確認付きの電源アイコンへまとめました。
- **本体と外部の分離**：本体Dockは外部Desktopから独立。通常の本体アプリは全画面起動を維持し、DesktopのDockではHOMEボタンを非表示。Dockのためだけの全幅／全高の空白帯を作らない配置へ整理しました。
- **グループ・ウィジェット**：グループをStartやデスクトップへ配置し、名前変更でも位置を保持。本体Dockの内向きスワイプにウィジェットパネルが追従します。編集は⚙から明示的に開始し、項目別の背景・不透明度・任意文字・画像に対応。画像はアプリ内へコピーし、本体／Desktopの配置を分離します。
- **PCヘルパー・説明書**：Windowsのワイヤレスデバッグ接続案内と右Alt単押しによるStart開閉、Linux／macOS用Bashランチャーを追加。操作・導入・開発履歴を別文書へ整理しました。
- **保守基盤**：設定・画面・タスク状態の管理役を定め、Android非依存のcore、検索、起動、特権bridgeへモジュール分離。逆方向の依存をビルド時に検査します。起動処理もcatalog／storage／policy／queue／executorへ分離し、push／PRごとにunit・lint・APKビルドを実行するCIを追加しました。

## 検証と残る範囲

- 性能修正のソースでJVMテスト161件成功。全Androidモジュールのlintはエラー0件（既存を含む警告あり）、debug／AndroidTest APKのビルド成功。
- 同じ性能修正APKをSOG06（Android 14）とREDMAGIC NX809J（Android 16）へ導入し、それぞれbridge・idleイベント・本体Dock・メニュー寿命・描画の5スコープのinstrumentationを確認。保存設定と画面サイズ・密度を保持し、所有した試験用タスク・画面・APKを清掃しました。
- 上記の機能検証は0.9.0表記の性能修正ビルドで実施。0.10.0への更新はバージョン情報とリリースノートの変更です。同じバージョン名だけで同じAPK・検証結果とは扱いません。
- 短時間のCPU観測は行いましたが、報告された電池使用割合11%の原因確定や、6時間以上の節電効果は未検証です。明示的な外部画面利用中に本体画面を消灯するためのWakeLockと、失敗した解除処理の有限リトライは意図して残しています。
- 物理USBの抜き差し、実マウスの入力先復帰、本体パネルの復旧、HOMEで既存ウィンドウが隠れる問題、アプリ固有のPiP、全OEM／Android 11の動作確認は別途継続します。
