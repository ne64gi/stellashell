# StellaShell 0.11.0 — Dock / Start / Window refresh

2026-10-10更新。versionCode: 20 / Shizuku UserService version: 38。開発中のプレリリースであり、安定版ではありません。

## 主な変更

- **アプリを外部へ表示**：アプリの長押し・右クリックに「外部に表示」を追加。接続中の外部画面へ、通常の起動設定を変えずに全画面での起動を要求します。ADB接続に依存しない経路で、複数画面は選択可能。専用モード中は本体を待機と終了だけの画面にし、StellaのDock・タスクバーを一時的に閉じます。アプリや端末側の制限によって起動できない場合があります。入力先固定や他アプリのタスクキルは行いません。
- **Dockの開き方**：1回タップ・2回タップ・スワイプを選択できます。本体は縦横共通、外部画面は別に保存。スワイプの反応範囲を広げ、斜め移動・スクロール・キャンセルと競合する誤操作を抑制しました。
- **Startの表示とキャッシュ**：本体とデスクトップで、表示するアプリとStartのピン留めを個別に設定できます。アプリ一覧・アイコンの取得を再利用し、パッケージ変更時の更新、閉じた画面の応答破棄、取得待ちの回復を整理しました。
- **Windows / Commandキー**：標準の全アプリ表示操作をStartへ接続。本体HOMEと外部画面の入口を整え、Windowsヘルパーの左右Windowsキー・右Alt単押し、修飾キーの組み合わせ、他PCアプリへフォーカスが移った場合の扱いを調整しました。Linux / macOSヘルパーもStartのキー入力とscrcpyのショートカットを分けます。
- **外部デスクトップの背景**：背景をクリックしたときに小窓を隠さない処理を追加し、Compact表示にも適用。壁紙・ウィジェット・ショートカットの操作画面を、背景の扱いと分けました。
- **外部タスクバーの更新**：タスク追加・切替・表示状態の変更では、タスクバーのWindowを作り直さず、アプリ項目だけを更新。ポインター操作・Start・右クリックメニューの途中では更新を延期し、終了後に最新状態を反映します。倍率とスクロール位置も保持します。
- **起動・本体設定**：タスク購読の起動時同期と画面の所有境界を調整。Android 14以前のデスクトップ準備では、既存の外部デスクトップモード設定を保持します。
- **SOG06の外部画面**：Android 14で接続時に作られる下部バーと、直接接続マウスの表示先を両立する互換処理を追加。セッション有効中の接続・切断イベントで動作し、待機中の定期ポーリングは行いません。既に黒帯がある接続は、StellaShellを有効にしてからケーブルを接続し直す必要があります。SOG06 / Android 14以外へこの回避処理は適用しません。

## 検証と残る範囲

- JVMテスト249件成功。全Androidモジュールのlintはエラー0件（既存を含む警告あり）、debug / AndroidTest APKのビルド成功。PCヘルパーはモック実行とキー判定のオフライン試験を確認しています。
- 「外部に表示」はSOG06へ導入し、通常アプリ権限で本体・無効な画面を起動先にできないことと、未接続時のメニュー非表示を確認。外部画面が未接続のため、実際の全画面表示・ADB停止時・コントローラー操作は未確認です。
- 追加の本体待機・専用モードもSOG06へ導入済み。二重開始、古いセッションの破棄、本体Dock/Taskbarの一時停止と最新設定での復帰を単体試験で確認しています。待機画面の実機寿命・物理入力・原神での動作は未確認です。
- 変更の開発ビルドでは、所有した試験用画面・隔離設定・合成タスクによるDock、Startキャッシュ、キー入力、タスクバーWindow寿命の検証を実施。試験スコープの成功と、試験終了後の設定復元は別に記録しています。試験起動時のHOME自動開始による選択先変更は、既知の差分だけを復元しました。
- REDMAGICで直接接続キーボードのStartと、Compact背景クリック後の小窓保持をユーザー確認済み。これらは先行する0.10.0表記の開発APKでの確認です。
- SOG06へ0.11.0の今回の開発APKを導入済み。保存設定・表示先・本体解像度を保持し、実機で互換処理の開始、設定スナップショット、明示終了、接続元終了、復元記録からの再開を確認しました。先行する手動回避では黒帯なし・マウス移動とクリックの両立をユーザー確認済みですが、今回の自動版での物理ケーブル再接続は別途確認が必要です。
- **REDMAGICのHDMI明滅は確認継続中**。小窓の再描画時に発生する報告に対してタスクバーWindowの再生成を減らしましたが、物理HDMIでの改善は未確認です。モニターの「信号なし」はケーブル抜き差しで表示が戻ることを確認しただけで、根本解消を保証しません。
- **電池消費の改善は未実証**。メモリ回収や短時間のCPU観測から節電効果を算出していません。実マウスの再接続、PiP、HOME・セッション再作成、Android 11、全OEM、Windows / macOS / Linuxの実環境確認などは別途継続します。

配布するのは開発用署名の本体APKです。AndroidTest APKは配布対象に含めません。標準HOMEを自動変更しません。

## その場Dock・HOME復旧（2026-10-10）

- 本体Dockの「ハンドル位置」に両サイド／右／左／ジェスチャー。選択時に練習チュートリアルが開き、上→左/右→離す操作で指の近くに縦並びのDockを表示します。アプリ一覧は上下スクロール、Dockをさらに横へ引くとウィジェットが開きます。
- 指での試行をもとに、大きめのL字・丸い曲がり方・ゆっくりした操作を認識するよう調整。練習枠の見えない除外領域を取り除き、途中の案内と指の位置を表示します。
- 任意位置モードは既定OFF。通常アプリの操作は奪わないため、同時にスクロールする場合があります。読取不可時はハンドルを表示し、消灯/ロック/無効化で読取を止めます。入力記録・注入・周期ポーリングは行いません。
- 標準HOMEがStellaShellの場合、HOMEを1.5秒以内に3回押すと設定タブを開きます。Dock・特権接続とは独立し、通常1回・内部HOME・履歴復帰を区別します。
- Bridge38（既存購読29/解除30）。実機のHOME3回、回転/ロック復帰、誤爆率・使用中CPU/電池は引き続き確認対象です。

最新の開発APK（`87780f0f`）はSOG06へ導入済み。249 JVM試験・lintエラー0に加え、実機上の練習画面への合成入力、縦Dockの配置・スクロール軸、ウィジェット引出しの要求を確認しました。更新後、ユーザーから使い心地について肯定的なフィードバックを得ていますが、全条件の実機検証完了を意味しません。専用外部モードの実操作・燃費は未確認、REDMAGICはこの版へ未更新です。
