# Phone Workspace

[ユーザーガイド](USER-GUIDE.md) · [セットアップ](setup/README.md) · [README](../README.md)

本体では通常のAndroidとして使い、外部画面ではDesktopへ切り替えるための補足です。日常の操作は[ユーザーガイド](USER-GUIDE.md)を参照してください。配布済みAPKとの差分は[リリースノート](RELEASES.md)で確認できます。

## 本体で使い始める

1. 起動メニューの **ホーム画面を開く** でStellaShellのホームを試します。標準ホームにするかは、Androidの選択画面で任意に決めます。
2. Dockを使うなら、Androidの「他のアプリの上に表示」を許可し、**設定 → 表示と動作 → Dock** で本体の表示をONにします。
3. Start・検索・ピン留めからアプリをタップすると、Android標準の全画面で開きます。小窓を使いたい操作だけ、長押し／右クリック → **小窓で開く** を選びます。

Start・検索・グループ・アプリの長押しメニューはDesktopと共通です。専用のPhoneアプリ一覧へ置き換えません。DockをOFFにした場合は、ホーム下部中央の **アプリメニューボタン** から同じStartを開けます。重ねて表示の許可がなく使えない場合も、ホームからStartを使えます。

ホームから別のアプリを開いても、設定で選んだ側の端からDockを呼び出せます。**他のアプリ上でもDockを表示** をOFFにするとホーム上だけになります。端末を横にしてもPhoneのままです。Back／Home／最近のアプリはAndroidの標準操作を使います。

## Dockの動作

本体ではスライド式Dock（旧サイドバー）を使います。外部Desktopの配置式Dockは、従来のタスクバーとは別の追加機能です。**Dockにピン留め** は本体とDesktopで保存先が分かれ、Desktopの **タスクバーにピン留め** とも別です。

本体タスクバーがOFFのときは、**スタート → 仕切り線 → ピン留め → 起動中（ある場合）→ 仕切り線 → ホーム画面へ** の縦並びです。本体タスクバーをONにするとDockのStartは非表示になり、タスクバー側のStartを使います。起動中があるときだけピン留めとの間に仕切り線を追加し、見出し文字は表示しません。

- ピン留めしたアプリのタップは通常起動。長押し／右クリックはアプリごとのメニューです。
- 起動中にはピン留めされていないアプリの本体タスクだけを表示し、タップすると同じタスクへ戻ります。新しいタスクの起動や外部への移動はしません。
- 起動中タスクの長押し／右クリックでは **サブウィンドウ化**／**タスク終了**、小窓なら **メインに戻す**／**タスク終了** を選べます。同じアプリの別タスクは対象にしません。
- 一覧を利用できないとき・取得中・取得失敗・空のときは、起動中の欄と余分な仕切り線を非表示にします。ピン留めと重なるアプリしかない場合も同じです。待機・エラーの文章はDockに出しません。
- 上下はスクロール専用です。小窓化や終了の上下ジェスチャーはありません。
- 内側への横スワイプはウィジェットパネルを開く操作です。呼び出した側からパネルとバーが指に追従します。通常時のウィジェット長押しは提供元へ渡し、編集は **⚙ → ウィジェットを編集** から始めます。

Dockには時計・バッテリー・クイック設定を出しません。本体のAndroid標準UI、または有効にしたタスクバーを使います。本体の表示・呼び出す側（両側／左／右）・上下位置と、Desktop Dockの表示・辺・横／縦位置は、同じ[Dock設定](USER-GUIDE.md#表示する側位置を変える)内で独立して調整できます。

Start・ピン留め・基本ホームにはShizuku接続は不要です。起動中のタスク一覧・切り替え・変換・終了と、明示的な小窓起動にはShizuku接続が必要です。OSの重ねて表示制限やサービス停止を回避するものではありません。接続確認は[セットアップのトラブル案内](setup/README.md#困ったとき)へ。

Stellaのウィンドウ枠は拡張機能の稼働先に選んだ1画面が対象です。外部Desktopのタスク操作と本体Dockのタスク操作は別で、枠を両画面へ同時表示する機能ではありません。本体の通常タップは、過去の起動設定が残っていても全画面です。

## 本体タスクバーを使う

**設定 → 表示と動作 → タスクバー** はDockとは別の設定画面です。**本体で表示する** は任意で初期OFFです。外部画面のタスクバーは常設で、OFF設定はありません。

本体で有効にすると、画面下部にStart・戻る・Home・タスクバー用ピン・起動中アプリ・撮影・バッテリー・設定・時計の横スクロールバーを出します。外部Desktopを使用中でも本体側は継続します。Dockはタスクバーの領域を避けて配置し、Startはタスクバー側だけに表示します。

起動中のタップは本体の同じタスクへ戻ります。YouTubeなどアプリ自身のPiP（動画の小窓）は、タップまたは **メインに戻す** で同じタスクを全画面へ戻します。長押し／右クリックから小窓化・全画面へ戻す・**タスク終了** を選べ、起動中のピン留めアイコンも対象です。終了は選んだタスクだけで、同じアプリの別タスクまで強制停止しません。Dockのピンとタスクバーのピンは別で、本体タスクバーのピンは最初は空です。アプリの配置メニューで **Dockにピン留め** と **タスクバーにピン留め** を選び分けます。

詳しい操作は[ユーザーガイド](USER-GUIDE.md#本体のタスクバー)、配布状況は[リリースノート](RELEASES.md)へ。

本体と外部画面のタスクバーのサイズは、この設定画面で **50〜200%** に調整できます。Dockにも別のサイズスライダーがあり、本体・外部画面それぞれの大きさを独立して調整します。初期値はすべて **100%** です。

## PhoneとDesktopの設定

Phoneは本体画面（Display 0）、Desktopは外部の物理／仮想画面です。縦横・解像度・Compact表示だけでは保存先を変更しません。

| 設定 | 保存範囲 |
| --- | --- |
| StartとDockのピン留め | Phone／Desktop別。StartとDockも別 |
| タスクバーのピン留め | Phone／Desktop別で各6枠。Dockとは別。本体は初め空、外部は従来のピンを維持 |
| ショートカット・グループの配置と位置 | Phone／Desktop別 |
| 壁紙・表示方法・焦点位置 | Phone／Desktop別 |
| ウィジェット・文字・画像の配置 | Phone／Desktop別。ホーム／デスクトップとウィジェットパネルも別 |
| アプリ本体とデータ・アイコンテーマ・アプリの非表示とグループ分け | 共通 |

初回だけ既存のピン・ショートカット・位置・壁紙設定をPhoneへ引き継ぎます。その後は片方の変更をもう片方へ反映しません。既存Desktopデータは残します。

PhoneのDockピンはスクロールでき、Desktop Dockのピン、本体・外部画面のタスクバー各6枠とは独立です。AndroidのウィジェットIDはコピーできないため、もう片方にも同じウィジェットが欲しい場合は追加し直してください。別の保存先へ既存配置を自動移動しません。

## 画面全体の表示サイズ

**設定 → 表示と動作 → ディスプレイ** で、本体・外部画面を名前から選び、文字やアプリの表示サイズを **50〜200%** に調整できます。**適用** で反映し、**標準に戻す** または100%の適用でその画面のAndroid標準サイズへ戻します。解像度は変えません。Shizuku接続が必要です。

これはDock・タスクバーだけのサイズスライダーとは別です。バーだけを大きくしたい場合は、それぞれのDock／タスクバー設定を使います。[表示サイズの使い分け](USER-GUIDE.md#画面全体の表示サイズ)を参照してください。

## 外部画面への切替

Phoneセッションで **接続時に外部画面へ移動** を有効にすると、新しく接続した対応外部画面を検出してDesktopへ切り替えます。初めて本体Dockを開始したとき、まだこの設定がなければONにします。既存の明示設定は上書きしません。

Shellの移動とタスクの移動は別です。通常起動した電話・決済などの本体タスクを勝手に取り込みません。Stellaが管理するタスクだけ移動を試み、切断時は本体へ戻します。端末・アプリに依存するため、全アプリの引き継ぎを保証しません。

外部Desktopを使用中も本体Dockは使えます。本体のDock表示、重ねて表示の許可、他のアプリ上での表示設定が必要です。

外部画面のタスクバーはDesktop／Compactのどちらでも下部の常設横バーで、項目を横にスクロールできます。Compactはワークスペースやアプリの表示に使う設定で、外部タスクバーの形状や常設条件は変えません。タスクバーのサイズに応じた下部領域を確保します。時計・バッテリー・設定・戻る・撮影はタスクバーに残します。Desktop Dockは別の追加機能で初期表示はOFF、デスクトップ表示ではピン留め・ピンと重ならない起動中アプリのアイコンだけで、Homeは表示しません。自動レイアウトでデスクトップ表示になった場合も同じです。Compact表示のDock・本体Dock・タスクバーのHomeは残します。Startは常設タスクバー側にあるので、外部Dockには表示しません。

Desktop Dockを使う場合は **設定 → 表示と動作 → Dock** で有効にします。左／右／上／下へ配置でき、横／縦のスライダーで画面の内側にも動かせます。追加Dockは端でも画面の内側でもアプリの上に重ね、Dock用の空白帯は取りません。タスクバーだけがサイズに応じた領域を確保し、Dockはその領域を避けて配置します。表示とピン留めはタスクバーとまとめません。外部タスクバーのサイズは別の **設定 → 表示と動作 → タスクバー** で調整します。

外部の物理画面またはscrcpyの独立した仮想画面が必要です。StellaShellの開始ボタンは仮想画面を作りません。[接続・セットアップ](setup/README.md)を参照してください。

## 検証の範囲

主な検証端末はSony SOG06／Android 14とREDMAGIC NX809J／Android 16です。機能単位の結果は[リリースノート](RELEASES.md)とそこから参照する検証資料に分けています。現行ソースの機能説明は、配布・導入・全端末の検証が済んだことを意味しません。

物理USBの抜き差し、OEM別の回転・キーボード・長期の標準ホーム運用などは未完了の確認を含みます。ビルド成功や他端末の試験結果で置き換えません。
