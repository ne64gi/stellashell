## 次版に向けた変更（未リリース）

- 本体サイドバーにアクティブなタスク一覧を復帰。Start・ピン留め・アクティブの縦スクロールと、既存の本体タスクへの切り替えに対応。
- アクティブ欄のアイコンに付いていた不透明な背景を除去し、ピン留めと同じ透明な通常背景・薄い選択色へ統一。
- アクティブ一覧の長押し／右クリックから、同じタスクのサブウィンドウ化・メイン（全画面）への復帰・対象タスク終了に対応。スクロールと競合する上下ジェスチャーは追加していません。
- 非アクティブな窓の×で、事前フォーカスに失敗すると閉じられない経路を修正。対象タスクを直接終了。
- HOME再開時の同期再入とactive出力cacheの不要な消去を抑制し、接続中の保存済み外部出力を復旧候補へ追加。

- 通知欄をアプリ別にまとめ、件数表示と折りたたみ／展開に対応。個別に開く・消す操作を維持し、Androidのまとめ通知の重複表示を抑制。
- 通知欄は各アプリの最新1件＋残件数から展開できるコンパクト表示へ。更新時の読み位置を保持し、送信者・時刻と通知ありの目印を追加。

- READMEを製品紹介に整理し、操作説明と開発履歴を別文書へ移動。
- Windowsランチャーにワイヤレスデバッグの対話式接続案内を追加。
- Linux／macOS用のBashランチャーを追加。5555やTermuxは必須ではありません。

- Startの⚙をデスクトップ／カスタマイズ／設定に分類。接続リセットは診断へ集約。
- 共通アイコン右クリックを起動方法／現在のウィンドウ／配置／カスタマイズに整理。

- HOMEでは終了操作を非表示。外部DesktopはStart右下の背景・枠なし電源アイコンからセッション終了（確認付き、端末電源操作とは別）。

- Startの設定はAndroid設定／StellaShell設定に統合。画面設定への重複導線を撤去し、Android設定は本体画面で開く。

- 外部画面へ直接起動してもHOMEのStart／設定への入口を維持。実際の本体サイドバー状態で切替。
- Windows helperの右Alt単押しでStella Start開閉。右Alt＋SpaceなどのMeta組み合わせは維持（APKとPS1双方の更新が必要）。

- 本体サイドバーを外部Desktopから独立させ、仮想画面への移動後も継続。
- 本体の通常起動は常に全画面、小窓は長押しから選択。時計・バッテリーを除去し、内向きスワイプで左右に合ったウィジェットパネルを表示。
- サイドバー設定の「スマホ」限定表記を除去。

- グループをStartへピン留め・デスクトップへ配置できるようにし、名前変更で位置を保持。
- 本体サイドバーのウィジェットボタンを撤去。内側スワイプでパネルを開きます。

- サイドバーの内向きスワイプにパネルとバーが一緒に追従。途中で戻す／キャンセルすると閉じます。
- ウィジェットの長押し編集を廃止。編集はパネルの⚙から明示的に開始します。
- 項目ごとの背景色・不透明度、任意の文字・画像を追加。画像はアプリ内へコピーし、Phone／Desktopで配置を分離します。
