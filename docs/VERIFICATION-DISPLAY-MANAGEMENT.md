# 出力先選択・画面管理の検証（2026-09-30）

## 変更

- 開始画面で外部出力先を画面名・Display IDから選択。開始ボタンも出力先を明記。
- 本体画面はDisplay 0と表示。起動中の表示と「デスクトップを表示」はサービスの実際の出力先を使用。
- 設定画面を開いている画面が、明示的に選んだ起動先を上書きしない。
- ワークスペース移動にも出力先選択を追加。
- 「画面管理」で接続中の画面を一覧表示し、特定できるscrcpy仮想画面を個別に終了。
- 本体・物理画面は終了対象外。画面ID、unique ID、shell UID、scrcpyのnew-displayコマンド、作成ログ、プロセス開始時刻を照合。古い識別情報・既に終了した画面は拒否。
- 確認済みセッションはBridgeの生存中に保持し、ログが流れた場合も現在のプロセスと照合。物理画面の明るさ・リフレッシュレート変更で一覧を無用に再構築しない。
- アプリ更新／プロセス再作成時に実行中表示が残る問題を修正。実行中表示はリセットし、開始画面を開くと保存済みの有効なセッションを再開。

## 制約

- 終了対応は特定できるscrcpyの仮想画面のみ。別の作成元・消失済み作成ログ・権限不足などで特定できない画面を推測で終了しない。
- scrcpyの該当セッションを終了するため、そのPC側接続も切れる。画面内のアプリの移動／終了はscrcpy・Android側の設定に依存する。
- USB物理画面の実接続は今回未検証。本体／物理画面には終了操作を提供しない。
- 起動先・作成元識別にはOEMのframeworkとShizukuの利用可否が関係する。
