## ホームとして使う

起動メニューの **ホーム画面を開く** で試せます。標準ホームにしたい場合だけ **標準ホームに設定** を選び、Androidの選択画面で設定してください。戻すときは **設定 → ホームアプリを変更** を使います。インストールや拡張機能の開始だけでは標準ホームは変わりません。

基本ホームのアプリ一覧・検索・通常起動・壁紙・ショートカットは、Shizukuや重ねて表示の許可なしで使えます。DockをOFFにしても、本体タスクバーからStartを開けます。どちらも使わない場合は、ホーム下部中央の **アプリメニューボタン** を使います。重ねて表示の許可がない場合もホームからStartを使えます。本体での通常タップはAndroid標準の全画面起動です。2つ目以降のアプリも自動で小窓にはなりません。

**拡張機能を停止**しても基本ホームは使えます。Android標準の最近のアプリやジェスチャー画面を置き換えるものではありません。

## Dockとタスクバー

**Dockとタスクバーは別の操作バーです。** アイコン中心のDockと、操作・状態表示を備えたタスクバーは、表示設定もピン留めもまとめません。

| 違い | Dock | タスクバー |
| --- | --- | --- |
| 主な役割 | ピン留め・ピンと重ならない起動中アプリ。Phone／CompactではHome、タスクバーがない画面ではStartも表示 | アプリ切り替え、戻る・Home、撮影、バッテリー、設定、時計 |
| 配置 | 本体は端から引き出すスライド式、外部画面は左／右／上／下や内側へ配置 | 本体は下部の横スクロールバー。外部画面は表示モードにかかわらず下部の常設横バーで、項目を横スクロールできる |
| 時計・バッテリー・設定・戻る・撮影 | 表示しない | タスクバーに表示 |
| 本体の初期表示 | ON | OFF |
| 外部画面での表示 | 初期OFF（必要な場合に有効化） | 常設。非表示にはできない |
| アプリのピン留め | **Dockにピン留め** | **タスクバーにピン留め**。本体・外部画面それぞれ6枠 |
| 設定画面 | **設定 → 表示と動作 → Dock** | **設定 → 表示と動作 → タスクバー** |

Dockの設定には **本体で表示する**／**外部画面で表示する** があり、個別にON／OFFできます。タスクバーは **本体で表示する** だけを切り替えます（初期OFF）。外部画面のタスクバーは常設で、OFF設定はありません。変更はその場で保存します。

同じ画面でタスクバーを表示している場合、DockのStartは非表示になります。アプリ一覧はタスクバーのStartから開きます。外部画面では常にこの構成です。

Start内のピン留め、Dockのピン留め、タスクバーのピン留めはそれぞれ別です。本体・外部画面とも、アプリメニューから **Dockにピン留め** と **タスクバーにピン留め** を選べます。ピン留めは操作した画面側へ保存し、Dockとタスクバー、本体と外部画面で自動共有しません。

### Dock・タスクバーの大きさ

それぞれの設定画面で、本体と外部画面のサイズを **50〜200%** のスライダーで調整できます。初期値は **100%** です。本体Dock・外部Dock・本体タスクバー・外部タスクバーは別々に調整でき、ピン留めの保存先は変わりません。

## 本体のDock

本体のスライド式Dockは、以前「サイドバー」と呼んでいたものです。Desktopのタスクバーとは別です。

画面の端からDockを呼び出します。外部デスクトップを使用中も、本体のDockは独立して利用できます。

| 項目 | タップ | 長押し／右クリック |
| --- | --- | --- |
| スタート（本体タスクバーがOFFのとき） | アプリ一覧・検索を開く | — |
| ピン留めしたアプリ | 通常の全画面起動 | そのアプリの起動・配置・カスタマイズ |
| 起動中のアプリ | 本体の同じタスクに戻る。PiPは全画面へ戻す | **サブウィンドウ化**／**タスク終了**。小窓・PiPなら **メインに戻す**／**タスク終了** |
| ホーム画面へ | ホーム画面を開く | — |

本体タスクバーがOFFのときの並び順は **スタート → 仕切り線 → ピン留めアイコン → 起動中アイコン（ある場合）→ 仕切り線 → ホーム画面へ** です。本体タスクバーがONならDockのStartは非表示にし、タスクバー側のStartを使います。起動中アイコンがある場合だけ、ピン留めとの間に仕切り線を追加します。「ピン留め」「アクティブ」の見出しは出しません。

- ピン留めしたアプリは、起動中でも下段には重複表示しません。ピンを解除すると、起動中のタスクは下段に戻ります。
- 起動中の一覧を利用できない場合、取得中・取得失敗・空の場合、または全タスクがピン留めしたアプリの場合は、下段と余分な仕切り線を出しません。接続待ちなどの状態文もDockには表示しません。接続の確認は[セットアップ](setup/README.md#困ったとき)へ。
- 上下はスクロール専用です。上下スワイプで小窓化・終了する機能や、そのON／OFF設定はありません。
- Dockを**画面の内側へ横スワイプ**すると、呼び出した側からウィジェットパネルを開きます。バーとパネルが指に追従し、十分に引いて離すと開き、途中で戻して離すと閉じます。専用ウィジェットボタンはありません。
- Dockには時計・バッテリー・クイック設定を表示しません。本体のAndroid標準UI、または有効にしたタスクバーを使います。

### 表示する側・位置を変える

**設定 → 表示と動作 → Dock** で変更します。外観設定とは別の画面です。

- **本体で表示する**：呼び出す側（両側／左／右）、呼び出し位置の上下スライダー、**他のアプリ上でもDockを表示**。
- 「他のアプリ上でも」をOFFにすると、ホーム表示中だけ呼び出せます。初期値はONです。
- **外部画面で表示する**：追加Dockは初期OFF。本体やタスクバーとは独立した表示ON／OFF、左／右／上／下、横位置・縦位置のスライダー。
- Dockの辺を選ぶと、まずその辺へ寄せます。その後は位置スライダーで画面の内側にも動かせます。表示を有効にしたときの初期位置は下辺中央です。追加Dockは端に寄せても内側へ浮かせてもアプリの上に重ね、Dock用の空白帯は取りません。タスクバーだけが大きさに応じた領域を確保し、Dockはその領域を避けて配置します。

本体とDesktopのDock表示・位置は独立しています。本体の回転だけでDesktopへ切り替わることはありません。

本体タスクバーの表示はDock設定に含めず、別の **設定 → 表示と動作 → タスクバー** で切り替えます。外部画面のタスクバーは常設です。本体にタスクバーを出したときは、その下部領域を避けてDockを配置します。

## 本体のタスクバー

**設定 → 表示と動作 → タスクバー → 本体で表示する** をONにすると、画面下部に横スクロールできるタスクバーを出します。初期値はOFFです。外部Desktopを使用中も、本体側のタスクバーは独立して使えます。

Start・戻る・Home・タスクバーへのピン留め・起動中アプリ・撮影・バッテリー・設定・時計を備えます。時計からウィジェット／通知、バッテリーからクイック設定を開きます。本体Dockのピン留めは引き継がず、タスクバーには別にピン留めします。

起動中アイコンのタップは本体の同じタスクへ戻ります。YouTubeなどアプリ自身のPiP（動画の小窓）では、そのタスクを全画面へ戻します。長押し／右クリックでは **サブウィンドウ化**／**タスク終了**、小窓・PiPなら **メインに戻す**／**タスク終了** を選べます。ピン留めした起動中アイコンからは **タスクバーから解除** も選べます。タスク一覧を利用できない場合も、待機やエラーの文章をバーには表示しません。接続確認は[セットアップ](setup/README.md#困ったとき)へ。

## アプリ・ピン留め・グループ

Startの検索でアプリを探し、タップして開きます。外側、Startの再押下、Back／Escで閉じます。

アプリの **長押し／右クリック** から、起動方法、配置、アイコンなどを変更できます。Start内へのピン留め、Dockへのピン留め、タスクバーへのピン留めは別です。本体・外部画面とも **Dockにピン留め** と **タスクバーにピン留め** をそれぞれ選べます。

- **表示するアプリ** では検索とチェック一覧でStartの表示・非表示をまとめて変更できます。**保存**で反映、**キャンセル**で破棄します。非表示にしてもアプリ本体や既存のピン・ショートカットは削除しません。
- アプリの配置メニューからグループを選べます。グループ内の設定から、含めるアプリをまとめて変更できます。アプリは1グループに所属し、別グループへ選ぶと移動します。
- Start内のグループを長押し／右クリック、またはグループ内の **⋯** から **デスクトップに追加**・**スタートにピン留め** を選べます。
- デスクトップのグループを押すとフォルダパネルを開きます。長押し／右クリックで移動・削除・Startへのピン留めを変更できます。
- グループ名の変更でピンや位置は失われません。グループを削除すると、そのグループのショートカットとピンも外れますが、アプリ自体は削除しません。
- デスクトップのショートカットは、マウスで直接ドラッグ、タッチでは長押し → **移動** → ドラッグで配置できます。空白メニューのグリッド吸着は任意です。

Phone／Desktopのピン留め・配置は別々です。詳しくは[保存する設定の違い](PHONE-WORKSPACE.md#phoneとdesktopの設定)を参照してください。

## ウィンドウ操作

本体で小窓を使いたいときは、アプリアイコンを **長押し／右クリック → 小窓で開く**。起動中のタスクなら **サブウィンドウ化** を選びます。Shizuku接続と端末のfreeform対応が必要です。

| 操作 | 動作 |
| --- | --- |
| タイトルバーをドラッグ | 対象の窓を前面へ出して移動 |
| 窓の端・角をドラッグ | サイズ変更（操作対象の窓） |
| 最小化 | 窓を隠す。タスクは終了しない |
| 最大化／元に戻す・左右スナップ | 対象の窓の配置を変更 |
| 小窓・PiPから **メインに戻す** | 同じタスクを全画面へ戻す |
| ウィンドウ枠の **×**／**タスク終了** | 選んだタスクだけを終了 |

起動中のタスクを **長押し／右クリック → タスク終了** でも閉じられます。外部画面のタスクバーでもメニューの先頭側に **タスク終了** があり、小窓・PiPには **メインに戻す** も表示します。ピン留めしたアイコンでも、起動中のタスクがあればこの操作を使えます。

アプリ自身が開いたPiPは、起動中アイコンのタップ、または **メインに戻す** で同じタスクを全画面へ戻します。通常の小窓を最大化する操作とは別です。

**×** は最小化ではありません。非アクティブな窓も、先に手前へ出さずに閉じます。同じアプリの別タスクまでまとめて強制停止する操作ではありません。

Desktopではアプリの起動メニューから、起動モード・初期サイズ・位置・前回の位置とサイズを記憶する設定を選べます。通常の **開く** は既存の窓があれば戻り、変更した起動設定は次回の新規起動に使います。**新しいウィンドウで開く** は別タスクを要求しますが、アプリ側の仕様で既存窓になる場合があります。本体の通常タップはこれらの設定にかかわらず全画面です。

Stellaのウィンドウ枠は拡張機能の稼働先に選んだ1画面が対象です。本体と外部の両方に同時表示するものではありません。

### 常に最前面（開発中）

対応する端末・画面の小窓では、タイトルバーのピンまたは長押しメニューの **常に最前面** で固定・解除できます。最小化・デスクトップ表示では隠し、復帰時に固定へ戻します。全画面化、非対応画面への移動、拡張機能の終了では解除します。アプリ再起動を跨ぐ永続設定ではありません。

Sony SOG06／Android 14は**本体画面のみ段階対応**です。外部・仮想画面では無効です。Sony標準ポップアップとの併用は未対応で、標準側が別の小窓を取り込み元の固定を解除する場合があります。

それ以外のAndroid 14以下、およびREDMAGIC NX809J／Android 16では無効です。Android 15以降も対応APIの有無と端末の動作に依存し、全機種での重なり・入力を保証しません。技術的な対応経路と検証状況は[タスクAPIの調査記録](TASK-API-PROVENANCE.md)を参照してください。

## ウィジェット・文字・画像

本体ではDockを内側へ引いて、または有効にしたタスクバーの時計から、ウィジェットパネルを開きます。外部画面でもタスクバーの時計から開けます。ホームやデスクトップにもウィジェットを配置できます。

**⚙ → ウィジェットを編集** から編集モードに入ります。通常時のタップ・スクロール・長押しは提供元のウィジェットに渡し、長押しではStellaの編集に入りません。

1. 編集パネルで対象を選びます。
2. 本体をドラッグして移動、右下のハンドルをドラッグしてサイズ変更します。
3. 必要ならパネルで横位置・縦位置・幅・高さを **1／8 dp刻み**、または数値指定で調整します。
4. **編集完了**／Back／Escで通常操作へ戻ります。

パネルは左右切替・折り畳みができ、追加・削除もパネル内で行えます。標準サイズ制限・自由リサイズ・縦横比固定を切り替えられます。サイズ変更後の内容の再配置は提供元に依存します。

### 項目の背景・文字・画像

- 項目を選び **項目の背景** で色と不透明度（0〜100%）を変更できます。文字・画像本体の透明度や、Androidウィジェットの提供元自身が描く背景は変更しません。
- **文字を追加** で内容・文字サイズ・色・揃え位置、**画像を追加** で画像を選べます。移動・サイズ変更はウィジェットと同じです。
- 画像は縮小してStellaShell内へコピーします。元ファイルを移動しても表示を維持します。

ホーム／Desktop、デスクトップ／ウィジェットパネルの配置は独立しています。既存のウィジェットIDと保存先は引き継ぎ、自動で別の画面へコピーしません。Androidウィジェットを別の場所にも置く場合は追加し直してください。

## 通知パネル

ウィジェットパネルの **通知** で、現在の通知をLINE・メールなどアプリごとにまとめて表示します。Androidの**通知へのアクセス**許可が別途必要です。

- 初めは各アプリの最新1件と **ほか○件** を表示します。見出しや展開ボタンで全件を表示し、折りたたむと最新1件へ戻ります。別ユーザー・仕事用の通知は混ぜません。
- 見出しの件数は現在ある通知の総数で、未読数ではありません。通知タブの小さな点も「通知がある」目印で、未読・新着判定ではなく、通知を開くだけでは消えません。
- 更新時も表示中の項目と読み位置をできるだけ維持します。送信者・本文・時刻はアプリが提供した情報を表示し、ない情報は補いません。
- 通知を押すと本体画面で開き、消せる通知の **×** でその通知だけを消します。Androidのまとめ通知は、同じグループの個別通知がある場合だけ重複を省きます。
- ロック中は内容を表示せず、通知履歴は保存しません。インライン返信や通知内アクションには対応していません。

## 外観・アイコン・壁紙

### 外観とフォント

**外観設定** でプリセット、バー・Start・パネルの色、アクセント色、不透明度を変更できます。ガラス風の半透明と縁取りに対応し、背景ぼかしはありません。

標準書体に加え、`.ttf`・`.otf`・`.ttc`ファイルを読み込めます。プレビューと保存は別で、キャンセルでは変更しません。アプリやAndroidウィジェットの内部、Androidシステムのダイアログには適用しません。[フォントの案内](FONTS.md)も参照してください。

### アイコン

**設定 → アイコン** でインストール済みのADW／Nova互換パックを選択できます。アプリの **長押し／右クリック → アイコンを変更**、または設定の **アプリごとに設定** で、パック内の別アイコンや画像を個別に指定できます。

優先順は **個別設定 → パックの対応アイコン → 標準アイコン**。「標準アイコンを使う」はそのアプリだけパックを無視し、「個別設定を解除」はパックに従います。ホーム・Start・Desktop・バーで共通です。画像は透過を保って最大256pxに縮小し、アプリ内へコピーします。

静的な対応表とアイコン一覧に対応します。動く時計・日替わりカレンダー・パック独自の背景／マスク合成は対象外です。パック削除や対応外のアプリでは標準アイコンへ戻ります。

### 壁紙

対象のホーム／Desktopから壁紙メニューを開きます。**壁紙の表示位置** でプレビューをドラッグ、または横／縦のスライダーで焦点を指定して保存します。

- **Fill**：画面を埋め、焦点を中心に近づけて切り抜きます。端では余白が出ないよう位置を制限します。
- **Fit**：画像全体を中央に収めます。余白が出るため焦点位置は使いません。

保存前のキャンセルでは変更しません。Phone／Desktopは別々に保存します。

## 画面全体の表示サイズ

**設定 → 表示と動作 → ディスプレイ** で、対象の本体・外部画面を名前から選び、画面全体の文字・アプリ・ウィンドウの表示サイズを調整します。解像度は変更しません。この操作にはShizuku接続が必要です。

1. 変更する画面を選びます。
2. 表示サイズを **50〜200%** のスライダーで選びます。**100%** がその画面の標準サイズです。
3. **適用** を押して反映します。スライダーを動かすだけでは変更しません。
4. 元に戻すには **標準に戻す** を使います。100%の適用も、その画面のAndroid標準設定へ戻します。

| 変えたいもの | 使う設定 |
| --- | --- |
| 画面全体の文字・アプリ・ウィンドウ | **ディスプレイ**。対象画面を選んで適用 |
| Dockだけの大きさ | **Dock** の本体／外部画面サイズスライダー |
| タスクバーだけの大きさ | **タスクバー** の本体／外部画面サイズスライダー |

Dock・タスクバーの4つのサイズスライダーは、画面全体の表示サイズとは別です。バーのサイズだけを変えても、他のアプリの文字や画面の解像度は変えません。

## 外部デスクトップ

外部の物理画面、またはscrcpyで作る独立した仮想画面を接続し、起動メニューで表示先を選んで開始します。接続や仮想画面の作成は[セットアップ](setup/README.md)を参照してください。

**接続時に外部画面へ移動** を有効にすると、新しい対応画面を検出してDesktopへ切り替えます。Shellの移動とアプリの移動は別です。通常起動した本体アプリを勝手に取り込まず、Stellaが管理するタスクだけ移動を試みます。切断時は本体へ戻します。端末・アプリに依存する動作で、物理USBの抜き差しは未検証です。

外部画面のタスクバーは、Desktop／Compactのどちらでも下部に常設する横バーです。項目が収まらない場合は横にスクロールできます。Compactはワークスペースやアプリの表示に使う設定で、外部タスクバーを端から呼び出す縦バーにしたり、自動で隠したりしません。タスクバーのサイズに応じた下部領域を確保します。追加のDockは必要に応じて有効にするアイコン中心の入口です。デスクトップ表示のDockは **ピン留め → ピンと重ならない起動中アプリ** の構成で、Homeは表示しません。レイアウトの自動選択でデスクトップ表示になった場合も同じです。Compact表示のDockと本体DockにはHomeを残し、タスクバーのHomeも引き続き使えます。Startは常設タスクバー側を使います。Dockに時計・バッテリー・設定・戻る・撮影は表示しません。表示設定とアプリのピン留めもタスクバーとは別です。

タスクバーの時計からウィジェット／通知、バッテリーからクイック設定を開きます。対応端末では **本体画面だけ消灯** でAndroidを起こしたまま本体パネルだけ消灯できます。通常のスリープとは別です。タスクバーの **▣** は表示中のDesktopの撮影で、対応環境では `Pictures/StellaShell` に保存します。

外部DesktopのStartの電源アイコンは、確認後にセッションを終了します。端末の電源を切る操作ではありません。停止しても基本ホームは無効になりません。変更した端末設定を元に戻す場合は、設定の診断から復元します。

## 対応範囲と制限

- Android 11以上がAPKの最低要件です。主な検証端末はSony SOG06／Android 14とREDMAGIC NX809J／Android 16で、Android 11の動作確認は未完了です。
- 小窓・タスク一覧・ウィンドウ操作はShizukuと端末側の対応に依存します。[必要条件](setup/README.md#必要な機能だけセットアップする)を確認してください。
- ロック画面やoverlay禁止画面ではバーと操作枠も非表示になります。Androidの通常の戻る操作／常駐通知で戻ってください。
- リサイズ枠は操作対象の1枚です。アプリの最小サイズ・向き指定はOS側に制限される場合があります。完全なOSウィンドウ管理の置換ではありません。
- 外部Desktopの稼働先は1画面を選択します。複数モニターへの同時展開、物理USB出力の動作保証、全OEMへの対応はありません。
- 日本語変換を使う場合、**仮想画面のスクリーンキーボードを非表示** はOFFにします。現在の設定はIME接続も無効にするためです。
- システム通知トレイとキーボードのスナップショートカットは未実装です。タスクの前後関係の更新には短い遅延があります。
