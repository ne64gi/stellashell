# StellaShell セットアップ

[README](../../README.md) · [ユーザーガイド](../USER-GUIDE.md) · [Phone Workspace](../PHONE-WORKSPACE.md)

導入・権限・接続・診断の入口です。日常のアプリ起動やカスタマイズは[ユーザーガイド](../USER-GUIDE.md)へ。**全部を実施する必要はありません。**

## 必要な機能だけセットアップする

Android 11以上がAPKの最低要件です。機種によって小窓・外部画面・ウィンドウ操作への対応が異なります。

| 使いたい機能 | 必要なもの | 手順 |
| --- | --- | --- |
| 基本ホーム・アプリ一覧・検索・通常の全画面起動 | StellaShell APK | 起動メニューの **ホーム画面を開く**。標準ホームの選択は任意 |
| 本体Dock | 「他のアプリの上に表示」の許可 | [① 権限とShizuku](01-shizuku.md#2-stellashellへ権限を渡す)、**設定 → 表示と動作 → Dock** |
| 本体タスクバー（追加機能） | 「他のアプリの上に表示」の許可。起動中操作にはShizuku | **設定 → 表示と動作 → タスクバー → 本体で表示する**（初期OFF） |
| 起動中タスクの一覧・切り替え・終了 | Shizuku API 13以降の起動と利用許可 | [① ShizukuとStellaShell](01-shizuku.md) |
| 小窓・完全なウィンドウ操作 | Shizuku、重ねて表示の許可、端末のfreeform対応 | [① ShizukuとStellaShell](01-shizuku.md) |
| 外部Desktop・常設タスクバー | 上記の拡張機能と、対応する外部画面 | [①](01-shizuku.md) → 画面接続 → 表示先を選んで開始。タスクバーのOFF設定はない |
| Desktopの追加Dock | 外部Desktopと重ねて表示の許可 | Dock設定でDesktopの表示を有効化（初期OFF）。タスクバーとは別 |
| 画面全体の文字・アプリの表示サイズ | Shizuku接続 | **設定 → 表示と動作 → ディスプレイ**。対象画面を選び、50〜200%で **適用**。解像度は変えない |
| PCに独立したDesktopを表示 | PCのADB接続・scrcpy | [①](01-shizuku.md) + [③ scrcpy](03-scrcpy.md) |
| Android単体から自己ADBを使う（上級者・任意） | Termuxなど | [② self-ADB](02-termux-self-adb.md) |
| 通知パネル | Androidの「通知へのアクセス」許可 | 通知パネルの設定から許可。StellaShell自身の通知許可とは別 |

USBモニターには端末側の映像出力対応が必要です。物理USBの抜き差しと全機種での動作は未検証です。PCで使う場合は②が不要で、USB ADBや通常のワイヤレスデバッグを使えます。ポート5555は必須ではありません。

## 接続ツールの役割

- **Shizuku**：他アプリのタスク・ウィンドウ操作に必要な権限の橋渡し。
- **ADB**：端末へのデバッグ接続。
- **scrcpy**：PCへの画面転送と、独立した仮想画面の作成。

ADB接続やペアリングに成功してもShizukuは自動で起動しません。StellaShellはADBサーバーの管理・ペアリング・Shizukuの自動起動をしません。self-ADBもShizuku起動の代行ではありません。

## 困ったとき

| 症状 | 確認する場所・操作 |
| --- | --- |
| 再起動後に起動中のアイコンが出ない／小窓操作が使えない | Shizukuが実行中か確認 → StellaShellの **設定 → 接続と権限 → Shizukuに接続**。利用許可も確認 |
| Startとピンは使えるが起動中が出ない | 起動中一覧だけに接続が必要。ピンと重なるアプリしかない場合も下段は非表示 |
| Dockが出ない | **設定 → 表示と動作 → Dock** の本体表示・呼び出す側・他のアプリ上での表示と、Androidの重ねて表示許可を確認 |
| 外部Dockが出ない | 追加Dockは初期OFF。同じ設定画面のDesktop Dock表示と稼働先、重ねて表示許可を確認 |
| 本体タスクバーが出ない | **設定 → 表示と動作 → タスクバー → 本体で表示する**（初期OFF）と、重ねて表示許可を確認 |
| 外部タスクバーが出ない | 外部タスクバーは常設。Desktopの稼働先・画面接続・重ねて表示許可を確認 |
| DockにStartが出ない | 同じ画面でタスクバーを表示しているときは、タスクバーのStartを使う。外部画面では常にこの構成 |
| バーが大きい／小さい | **設定 → 表示と動作 → Dock** または **タスクバー** で、本体・外部画面のサイズを調整（50〜200%、初期100%） |
| 画面全体の表示サイズを戻したい | **ディスプレイ** 設定で対象画面を選び **標準に戻す**。Dock／タスクバーのサイズとは別 |
| PiPの動画を全画面へ戻したい | 起動中アイコンをタップ、または長押し／右クリック → **メインに戻す**。タスク操作にはShizuku接続が必要 |
| アプリの窓を閉じたい | 起動中アイコンの長押し／右クリック → **タスク終了**。選んだタスクだけを閉じる |
| 接続をリセットしたい／端末設定を戻したい | **設定 → 診断**。拡張機能の停止だけでは変更した端末設定は復元しない |
| scrcpy・ADBの接続や日本語入力で困る | [③ scrcpyの接続・入力](03-scrcpy.md) |
| 通知が出ない | Androidの通知へのアクセス、端末ロック状態を確認 |

Dock内には接続待ち・取得中・取得失敗の文章を表示しません。起動中一覧がないことだけで、OSやアプリの不具合と決めないでください。ロック画面やAndroidが重ねて表示を禁じる画面では、バーや枠も出ません。
