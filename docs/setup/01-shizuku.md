# ① 権限とShizukuのセットアップ

[セットアップの入口](README.md) · [ユーザーガイド](../USER-GUIDE.md)

基本ホームだけならShizukuは不要です。本体Dock・タスクバーには重ねて表示の許可、起動中タスク一覧や小窓操作にはShizuku、自由形式の小窓には端末のfreeform対応が必要です。使う機能に合わせて進めてください。

## 必要なもの

- Android 11以上とStellaShell APK。配布時の版・検証記録を確認してください。
- タスク・ウィンドウ操作を使う場合は、[Shizuku公式](https://shizuku.rikka.app/)から案内されているShizuku（API 13以降）。
- 小窓を使う場合は端末側のfreeform対応。
- 外部画面で使うなら映像出力対応の端末・モニター、または[③ scrcpy](03-scrcpy.md)。USB-C端子があるだけでは映像出力対応とは限りません。

Termux・self-ADB・ポート5555は必須ではありません。

## 1. Shizukuを起動

Shizukuの「ワイヤレスデバッグで開始」の案内に従い、Androidの開発者向けオプションでワイヤレスデバッグを有効にし、ペア設定コードでペアリングして開始します。ペアリング成功だけで終わらず、Shizuku画面で **実行中** を確認してください。

画面・操作名やOEM制限は[Shizuku公式セットアップ](https://shizuku.rikka.app/guide/setup/)を優先します。PC経由で起動する場合はUSBデバッグを有効にし、インストールしたShizuku自身が表示するADBコマンドを使います。この文書では起動ファイルの固定パスを指定しません。

## 2. StellaShellへ権限を渡す

**設定 → 接続と権限** を開きます。

1. **重ねて表示する権限** からAndroid設定を開き、StellaShellの「他のアプリの上に表示」を許可します。
2. **Shizukuに接続** を選び、Shizukuの許可ダイアログでStellaShellを許可します。
3. セットアップ画面でShizuku接続・操作バーの表示許可を確認します。

StellaShell自身の通知許可も求められる場合があります。他アプリの通知を表示するための「通知へのアクセス」とは別です。

APKのインストール、Shizuku実行中、StellaShellへの利用許可、接続成功は別々の状態です。Dockとタスクバーにはそれぞれ **設定 → 表示と動作 → Dock**／**タスクバー** の専用設定画面があります。Dockは本体・外部画面で個別に表示を切り替え、本体タスクバーは任意（初期OFF）、外部タスクバーは常設です。本体Dock・タスクバーをどちらも使わない場合でも、ホームの **アプリメニューボタン** からStartは使えます。

## 3. ウィンドウ機能を設定

小窓やDesktopを使う場合、**設定 → アプリのウィンドウ → ウィンドウ機能をセットアップ** を開き、説明を読んで有効にします。

freeformを有効にし、Androidの「外部画面でデスクトップモードを強制」はOFFにします。後者を手動でONにすることをセットアップ条件にしないでください。元の値は復元用に保存します。

変更を反映するために画面を再接続します。端末側で再起動が必要な場合は、再起動後にShizukuも起動し直してください。この操作だけでは標準ホームは変わりません。

## 4. 表示先を選んで開始

起動メニューで表示先を選び、拡張機能を開始します。

- **本体画面**：スマホ／タブレット自身で使用します。
- **外部画面**：モニター接続、またはscrcpyで仮想画面を作成してから選びます。

外部Desktopではタスクバーが常設で、OFF設定はありません。Desktop Dockは別の追加機能で初期OFF、必要な場合にDock設定から有効にします。時計・バッテリー・設定・戻る・撮影はタスクバーに残し、Dockとは分けています。同じ画面にタスクバーがある場合、DockにはStartを表示せず、タスクバー側のStartを使います。本体・外部画面のDock／タスクバーのサイズは、それぞれの専用設定画面で50〜200%（初期100%）に調整できます。

StellaShellの開始ボタンは仮想画面を作りません。最初は電卓などで起動・移動・サイズ変更を確認します。本体の通常タップは全画面起動で、小窓は **長押し／右クリック → 小窓で開く** で明示的に選びます。

## 任意の追加許可

- ウィジェットはパネルの **⚙** から追加・編集。Androidの作成許可と提供元の設定画面が出る場合があります。長押しではStellaの編集に入りません。
- 他アプリの通知を読むには、通知パネルの設定からAndroidの **通知へのアクセス** を別途許可します。
- 壁紙・フォント・画像はファイル選択から読み込みます。Shizukuでファイルアクセスを代行しません。
- 標準ホームにする場合だけ、起動メニューの **標準ホームに設定** からAndroidの選択画面へ進みます。

## 画面全体の表示サイズ（任意）

文字・アプリ・ウィンドウ全体を大きく／小さくしたい場合は、Shizuku接続後に **設定 → 表示と動作 → ディスプレイ** を使います。本体・外部画面を名前から選び、50〜200%を指定して **適用** します。**標準に戻す** または100%の適用で、その画面のAndroid標準サイズへ戻します。解像度は変更しません。

Dock・タスクバーだけを調整する4つのサイズスライダーとは別です。バーだけのサイズ変更に、この画面全体の操作は不要です。

## 次回起動・停止・復元

非root環境では端末再起動後にShizukuを起動し直します。起動後、StellaShellの **設定 → 接続と権限 → Shizukuに接続** で再接続・許可を確認できます。自動でShizukuを起動する機能ではありません。

拡張機能を停止しても、基本ホームと保存した配置は残ります。変更した開発者設定を戻す場合は **設定 → 診断 → 変更前の端末設定に戻す** を選びます。停止だけでは端末設定は戻りません。

症状別の確認は[セットアップの「困ったとき」](README.md#困ったとき)、PC接続と入力は[③ scrcpy](03-scrcpy.md)を参照してください。全端末の動作保証ではありません。
