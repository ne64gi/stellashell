# StellaShell 0.11.1 — 拡張機能・向き別Dock / ホーム2回でStart

2026-10-10。versionCode: 21 / Shizuku UserService version: 39。開発中・未公開の版です。

## 変更

- クイック設定の1.5秒ごとの取得を廃止し、表示中の変更通知で必要な項目だけ更新。閉じた後や再表示前の古い通知は反映しません。
- 画面領域が変わらないときの共有状態更新と、未使用の領域診断を設定ファイルへ書き続ける処理を削減。回転・キーボード表示の通知は維持します。

- 本体Dockの呼び出し方を縦向き・横向きで独立保存。横向きの初期値は下端ハンドル＋スワイプで、縦向きだけL字ジェスチャーにできます。
- 回転後の配置更新で、直前に開いた新しいジェスチャーDockまで閉じてしまう競合を修正。
- 端ハンドルからDockを開いた後、同じ方向への2回目pullでウィジェットを表示。上・下のハンドルにも対応し、引き出し中に回転したら旧操作を取り消します。L字で出した場合は最後の横方向と逆へ引き戻します。
- ウィジェットの位置・サイズ・表示モードを本体縦／本体横／外部に分離。旧配置を初期値にし、既存の保存先・内容・AndroidウィジェットIDを維持します。

- 追加機能の名称は **拡張機能** に統一。デスクトップのウィンドウ管理はこちらに含め、ミラーリング・1アプリの **外部に表示** は切替不要の基本機能として区別します。

- 通常HOME・Start・画面端のDockと、Shizukuを使う任意の**拡張機能**を分離。通常のDock開始にShizukuは要求しません。
- **設定 → 拡張機能**にON/OFF、Shizuku接続、ウィンドウ設定、画面全体の倍率、診断をまとめました。新規はOFF、既存利用者の設定は引き継ぎます。
- OFFにしても通常のシェルとピン・配置を保持。追加の入力監視・タスク通知・一時的な端末制御を解放し、失敗した終了処理は再試行できます。
- SDK・Provider・接続処理はplatform側、モード選択と状態管理は専用ownerへ分離。古い接続や移送の返答で通常機能を停止・保存先を変更しないようにしました。

- StellaShellが標準ホームの場合、**ホームを素早く2回**押すと本体のスタートランチャーを開きます。間隔は600ミリ秒以内。Dockや特権接続が使えない場合にも利用できる入口です。
- 3回押しで設定を開く操作を廃止しました。設定画面自体と、通常のメニューからの設定への入口は残しています。
- 1回だけのホームは従来どおりです。内部のホーム要求・履歴復帰・画面再生成を2回押しに数えず、同じ通知の重複でランチャーが閉じることも防ぎます。
- ホームを押したまま上へ動かす操作は、この版には含めていません。

## ウィジェットパネル・編集UIの追加変更

- ウィジェットパネルにページ追加・移動・空ページ削除。既存項目は1ページ目に保持し、縦／横／外部でページ分けと最後のページを保存します。
- 本体では開いた側の下寄りへ、ウィジェット／通知・設定・閉じるを集約。外部デスクトップは従来の下部タブ。最後のタブも別々に保存します。
- Dockのピン留め・起動中一覧で、通知ありのアプリを各一覧の先頭へ表示し、件数をアイコンに重ねます。保存順は変更せず、まとめ通知の重複と別ユーザーの通知を除外。Start／タスクバーの並びは変更しません。
- 通常編集は小型インスペクターと直接ドラッグ／リサイズ。詳細は「配置・表示・管理」に分け、対象別の項目と削除確認を維持します。ウィジェットID・既存の配置／背景／内容は引き継ぎます。
