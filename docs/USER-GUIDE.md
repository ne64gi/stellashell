# StellaShell ユーザーガイド

[READMEへ](../README.md) · [Phone Workspace](PHONE-WORKSPACE.md) · [セットアップ](setup/README.md)

## 任意のホームアプリとして使う（開発中）

ダッシュボードの **ホーム画面を開く** で試し、**標準ホームに設定** からAndroidの選択画面で設定できます。**設定 → ホームアプリを変更** で元のホームに戻せます。インストールや拡張機能の開始だけでは標準ホームは変わりません。

- 基本ホーム：アプリ一覧・検索・通常起動・壁紙・ショートカットはShizukuやオーバーレイ許可なしで使えます。
- 拡張機能：本体では通常タップで標準Androidの全画面起動を行います。小窓で使う場合は、長押し／右クリックから **フローティングで開く** を選びます（Shizuku・端末のfreeform対応が必要）。2つ目以降のアプリも自動では小窓になりません。
- サイドバーは **スタート → ピン留め → アクティブ** の縦スクロール構成です。アクティブは本体の既存タスクへ戻る入口で、この一覧と切り替えにはShizuku接続が必要です。
- アクティブの長押し／右クリックで **サブウィンドウ化**（小窓なら **メインに戻す**）または **タスク終了** を選べます。全画面と小窓の切り替えは同じタスクを変換し、終了は選んだタスクだけが対象です。上下操作はスクロールのままで、終了ジェスチャーはありません。
- サイドバーは外部Desktop使用中も本体に残ります。本体の時計・バッテリー・クイック設定はAndroid標準UIに任せ、サイドバーを画面の内側へスワイプすると、呼び出した側からウィジェットパネルを開きます。
- **拡張機能を停止**してもホーム用Activityは無効にしません。HOME入口は外部画面用SECONDARY_HOMEと分離しています。
- ホームのウィジェットは既存の外部デスクトップ／Hubとは別の保存先・Hostです。既存配置を自動移動しません。
- Android標準の最近のアプリ／ジェスチャー画面を置換する機能ではありません。再起動後・OEM別の標準ホーム運用は引き続き検証対象です。


## アイコンのカスタマイズ（開発中）

- ダッシュボードの **設定 → アイコン** で、インストール済みのADW／Nova互換パックを選択できます。
- アプリを **長押し／右クリック → アイコンを変更** すると、パック内の別アイコンや画像ファイルを個別に設定できます。設定画面の「アプリごとに設定」からも選べます。
- 優先順は個別設定 → パックの対応アイコン → 標準アイコン。「標準アイコンを使う」はそのアプリだけパックを無視し、「個別設定を解除」はパックに従います。
- ホーム・スタート・デスクトップ・タスクバーで共通です。画像は透過を保って最大256pxに縮小し、アプリ内にコピーします。ストレージ全体への権限は不要です。
- 静的な`appfilter.xml`対応表と`drawable.xml`一覧に対応します。動く時計・日替わりカレンダー・未対応アイコンへのパック独自の背景／マスク合成は対象外です。パック削除や対応外のアプリでは標準アイコンへ戻ります。


## ウィジェットの配置・編集

- **⚙ → ウィジェットを編集** から編集モードに入ります。長押しでは編集に入りません。編集中は本体をドラッグして移動、右下のハンドルをドラッグしてサイズ変更できます。通常時のタップ／スクロールはウィジェットに渡します。
- サイドパネルで対象を選び、横位置・縦位置・幅・高さを **1 / 8 dp刻み** または数値指定で調整できます。パネルは左右切替／折り畳み可能で、配置用の余白を追加しません。
- 標準サイズ制限・自由リサイズ・縦横比固定を切り替えられます。追加・削除もパネル内。**編集完了**／Back／Escで通常操作へ戻ります。
- ホーム・外部デスクトップ・時計のウィジェットパネルで共通の操作です。既存のウィジェットIDと保存先は引き継ぎます。


## 通知パネル

- ウィジェットパネル下部の **通知** で、現在の通知をLINE・メールなどアプリごとにまとめて表示します。見出しの件数はそのアプリの通知総数で、未読数ではありません。
- 最初は各アプリの最新1件を表示し、残りは **ほか○件** にまとめます。見出しや展開ボタンで全件表示でき、折りたたむと最新1件へ戻ります。仕事用など別ユーザーの通知は混ぜません。
- 通知更新時も表示中の項目・読み位置をできるだけ維持します。会話通知では送信者と本文、通知には時刻を表示します。アプリが提供していない情報は補いません。
- 通知タブの小さな点は「現在通知がある」目印です。未読や新着を判定するものではなく、通知を開いただけでは消えません。
- 通知を押すと本体画面で開き、各通知の **×** でその通知だけを消します。Androidのまとめ通知は、同じグループの個別通知がある場合だけ重複表示を省きます。
- Android設定で通知へのアクセス許可が必要です。ロック中は内容を表示せず、通知履歴は保存しません。


## ウィンドウを閉じる

- ウィンドウ枠の **×** は対象タスクを終了します。最小化ではありません。非アクティブなウィンドウも先に手前へ出さずに閉じます。
- 同じアプリの別タスクまでまとめて強制停止する操作ではありません。


## ウィンドウを最前面に固定（開発中）

- Android 15以降の対応端末では、タイトルバーのピン／長押しメニューの **常に最前面** で小窓ごとに固定・解除できます。別の窓を操作しても固定窓を手前に保ちます。
- 最小化・デスクトップ表示では隠し、復帰時に再び固定します。全画面への変更や拡張機能の終了では解除します。アプリ再起動を跨ぐ永続設定ではありません。
- Android 14以下ではOS側のタスク単位APIが揃わないため無効表示です。NX809JのAndroid 16でもネイティブ固定要求時に呼出プロセスが終了するため無効にしています。他の対応OSでの実際の重なり・入力の実機確認は継続中です。


## Requirements / デスクトップ拡張機能のセットアップ

- Android **11以上**（minSdk 30）。動作検証はSony SOG06 / Android 14、REDMAGIC NX809J / Android 16。
- **Shizuku API 13以降**が起動・許可済み。タスク一覧、移動、リサイズなどの完全なウィンドウ操作に必要。
- 端末frameworkの **freeform windowing対応**。OEMによって対応APIや動作が異なります。
- **multi-display対応**と外部ディスプレイ（物理出力、またはscrcpyの仮想画面）。外部画面モードのみ必要です。本体画面モードは外部ディスプレイ不要です。
- 「他のアプリの上に表示」の許可。

通常の導入は **Shizuku → StellaShell** です。初めてなら [Shizuku公式セットアップ](https://shizuku.rikka.app/guide/setup/) を参照し、StellaShellの設定画面でShizuku接続・許可、操作バーの表示許可、Desktop Shell用の設定、開始の順に進めてください。

Shizuku停止時は設定画面に状態を表示します。Shizuku側で起動した後、**「Shizuku に接続・許可」** で再試行できます。StellaShell自体はADBサーバーの管理・ペアリング・Shizukuの自動起動を行いません。

### Advanced / self-ADB（任意）

Termuxから自己ADBを利用したい場合のみ、[初回セットアップ](../tools/setup-self-adb.sh) と日常用 [adb5555](../tools/adb5555) を利用できます。[使い方・制約](../tools/README.md) を参照してください。これらはStellaShellの必須セットアップではなく、Shizukuの起動を代行するものでもありません。


## scrcpy の独立画面

`DEVICE_IP` はADB接続済み端末のIPアドレスに置き換えてください。

```sh
scrcpy -s "$DEVICE_IP:5555" --new-display=1920x1080/160 \
  --no-vd-system-decorations --display-ime-policy=local \
  --start-app=net.fuyumori.stellashell
```

初回は本体で「他のアプリの上に表示」、通知、Shizuku を許可。設定の **Desktop Shell 用に設定する** は、freeform を有効にし、Android の強制デスクトップモードをオフにします。変更前の値を保存し、復元できます。適用後は scrcpy / USB を再接続してください。

`force_desktop_mode_on_external_displays=1` は `--no-vd-system-decorations` にかかわらず Android のナビゲーション領域を作り、バーの入力を奪います。0.3 の実機設定は **force desktop=0 / freeform=1** です。これは本体のホームアプリ変更ではありません。

Shizuku が切れるとタスク一覧・ウィンドウ操作は停止します。全画面アプリ起動は通常 API でも可能ですが、freeform 指定時は接続エラーを表示し、別画面へ勝手に転送しません。


## 現時点の制限

- Android のロック画面や「画面設定」など overlay 禁止画面では、バーと操作枠も非表示になります。通常の戻る操作／常駐通知でデスクトップへ戻してください。禁止を解除する回避策は入れていません。
- リサイズ枠はアクティブな1枚のみ。タイトルバーは見えている各freeform窓に表示しますが、完全なOSウィンドウマネージャーの置換ではありません。
- アプリ独自の最小サイズ・向き制約は OS に制限される場合があります。
- 物理 USB モニタはこの版で未検証。複数モニタ同時ではなく1画面を選択します。
- システム通知トレイ、キーボードのスナップショートカットは未実装。
- タスク監視は通常約1.1秒、複数窓表示時は約0.3秒間隔。外部からの前後関係変更にはその遅延があります。ドラッグは最新位置に集約し、Binder 要求を無制限に積みません。


## ビルドと検証

JDK 17、Android SDK Platform 35 / Build Tools 35.0.0 が必要です。`ANDROID_HOME` を設定するか、ローカルの `local.properties` に `sdk.dir` を指定してください。Gradle 8.11.1 はWrapperで取得します。

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`（開発用署名）

## Windowsから仮想デスクトップを開始

[Windows用セッションランチャーとJSONサンプル](../tools/windows/README.md) を同梱しています。端末名で接続先を選択し、scrcpyで仮想画面を作ってStellaShellを起動します。scrcpy / ADB本体は別途必要です。

## グループの配置

- Start内のグループを長押し／右クリック、またはグループ内の **⋯** から **デスクトップに追加**・**スタートにピン留め** を選べます。
- デスクトップのグループをクリックするとフォルダパネルが開きます。長押し／右クリックで移動・削除・Startのピン留めを変更できます。
- Phone／Desktopの配置は別々です。グループ名の変更でピンや位置は失われず、グループ削除時にはそのショートカットとピンも外れます（アプリ自体は削除しません）。
- サイドバーのウィジェット専用ボタンはありません。サイドバーを内側へスワイプしてパネルを開きます。

### 項目ごとの背景・文字・画像

- 編集パネルで項目を選び **項目の背景** から色と不透明度（0〜100%）を変更できます。文字・画像本体の透明度は変わりません。Androidウィジェットのアプリ自身が描く背景は変更しません。
- **文字を追加** で文章・文字サイズ・文字色・揃え位置を設定できます。**画像を追加** で選んだ画像を配置できます。どちらも既存ウィジェットと同じ移動・サイズ変更が使えます。
- 画像は縮小してStella内へコピーするため、元ファイルを移動しても表示を維持します。Phone／Desktop、デスクトップ／ウィジェットパネルの保存先はそれぞれ独立しています。
- サイドバーからの横スワイプでは、サイドバーとパネルがつながって指に追従します。十分に引いて離すと開き、途中で戻して離すと閉じます。
