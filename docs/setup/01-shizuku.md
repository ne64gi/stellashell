# ① Shizukuを使ってStellaShellをセットアップする

[手順の入口](README.md) · 対象：StellaShell 0.7

## 必要なもの

- Android 11以上（APKの最低要件）。端末側のfreeform対応が別途必要です。
- StellaShell APK。配布時のバージョン・検証記録を確認してください。
- [Shizuku公式](https://shizuku.rikka.app/)から案内されているShizuku。
- 外部画面で使うなら映像出力対応の端末・USB-Cハブ／モニター、または[③ scrcpy](03-scrcpy.md)。USB-C端子があっても映像出力対応とは限りません。

Termux・self-ADB・ポート5555は必須ではありません。

## 1. Shizukuを起動

Androidの開発者向けオプションからUSBデバッグとワイヤレスデバッグを有効にします。
Shizukuの「ワイヤレスデバッグで開始」の案内に従い、Androidの「ペア設定コードによるデバイスのペア設定」で表示されたコードを入力してペアリングし、Shizukuを開始します。
ペアリングの成功だけで終わらず、Shizuku画面で**実行中**を確認してください。

画面・操作名やOEM制限は [Shizuku公式セットアップ](https://shizuku.rikka.app/guide/setup/)を優先してください。PC経由で起動する場合は、インストールしたShizuku自身が表示するADBコマンドを使用します。バージョンによって起動ファイルの場所が異なるため、この文書では固定パスを指定しません。

## 2. StellaShellへ権限を渡す

1. StellaShellを開き、通知許可を求められたら必要に応じて許可。
2. **設定 → 重ねて表示する権限**を押し、Android設定でStellaShellの「他のアプリの上に表示」を許可。
3. 戻って **設定 → Shizukuに接続**。Shizukuの許可ダイアログでStellaShellを許可。
4. StellaShellの状態表示が **Shizuku接続済み**・**操作バー：許可済み**になっていることを確認。

「インストール済み」「Shizuku実行中」「StellaShellへの許可済み」は別々の状態です。

## 3. デスクトップ機能を設定

**Desktop Shell用に設定する**を開き、確認内容を読んで有効にします。
現在の実装ではfreeformを有効にし、Androidの「外部画面でデスクトップモードを強制」はOFFにします。後者を手動でONにすることをセットアップ条件にしないでください。
元の設定は復元用に保存されます。変更が反映されない場合はディスプレイを再接続します。端末によって再起動が必要なら、再起動後にShizukuも起動し直します。

## 4. 表示先を選ぶ

- **本体画面でデスクトップを開始**：スマホ／タブレット自身で使用。標準ホームアプリを置き換える設定ではありません。
- **開始 → 外部画面で開始**：USBモニターを接続、またはscrcpyで仮想画面を作成してから使用。ボタンだけでは仮想画面は作られません。

最初は電卓など軽いアプリで起動・ドラッグ・サイズ変更を確認します。特定アプリが全画面になる場合は、右クリック／長押しの起動モードと、アプリ側の制約を確認してください。

## 任意の追加許可

- 時計→ウィジェット→⚙から追加。Androidのウィジェット作成許可と提供元の設定画面が出る場合があります。
- 通知パネルの⚙→「通知へのアクセス設定」から他アプリの通知を読むには、Androidの**通知へのアクセス**を別途許可。StellaShell自身の通知表示許可とは異なります。
- 壁紙・フォントはファイル選択から読み込みます。Shizukuでファイルアクセスを代行するものではありません。

## 次回起動・トラブル時

| 症状 | 確認 |
| --- | --- |
| Shizukuが停止しています | Shizukuを起動→StellaShellで再試行。非rootでは端末再起動後に再起動作業が必要 |
| 実行中なのに接続できない | Shizukuの許可アプリでStellaShellを確認 |
| バーが出ない | オーバーレイ許可、表示先、本体のスリープ状態を確認 |
| マウスが本体にしか出ない | Shizuku接続と診断欄を確認し、画面・マウスの接続をリセット |
| 日本語変換できない | 「仮想画面のスクリーンキーボードを非表示」をOFF。これはIME接続も無効化する設定 |
| 終了したい | StellaShell設定の「デスクトップを終了」。変更した開発者設定は復元ボタンで戻せます |

全端末の動作保証ではありません。Shizuku非稼働時の具体的制限は [Capability Matrix](../LIMITED-MODE-0.7.md) へ。

## 本体画面・タブレットのレイアウト

設定の「シェルのレイアウト」で次を選べます。

- **自動**：利用可能なdpサイズで選択。小さい画面はCompact、広い画面はDesktop。
- **デスクトップ タスクバー**：従来の下部バーを固定で使用。
- **コンパクト エッジDock**：左右の下寄りハンドルを内側へスワイプ（またはタップ）。操作した側にDockが出ます。

Compactでも星はStart、時計はウィジェット／通知、バッテリーはクイック設定です。
スクリーンショットボタンはDesktopのみ表示します。端末のモデルやDisplay番号だけでは
レイアウトを決めないため、本体画面のタブレットでもDesktopを選べます。

## 起動メニュー

- **開始**：接続状態、本体／外部画面での開始、実行中の表示・終了・画面引き継ぎ。
- **設定**：権限、ウィンドウ機能、外観、レイアウト、キーボード、試験機能。
- **診断**：接続リセット、端末設定の復元、診断ログとコピー。
